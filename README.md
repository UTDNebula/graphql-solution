GraphQL Workshop Solution Fall 2026

Do not edit models_gen.go or generated.go. Those are generated from gqlgen.

After editing the GraphQL schema, run `go tool gqlgen generate` to auto generate the Go struct corresponding to the GraphQL models and the event resolver method stubs.

To run the GraphQL server, run `go run server.go`

Solutions to the main challenges are in `main` branch. Solutions to the additional challenges are in the `additional-challenges` branch.
